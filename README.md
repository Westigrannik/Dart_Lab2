5. Ответы на вопросы:

1. В чём разница между полем класса и обычной переменной в функции?
- Нам достаточно описать что-то один раз в классе, чем просто в переменной
2. Что такое конструктор и зачем он нужен?
- Специальный метод, который вызывается при создании объекта
3. Зачем нужен @override перед toString()? Что будет если его убрать?
- @override для toString —
это переопределение метода класса Object, от которого в Dart неявно наследуются все
классы. Без этого ничего не будет
4. Чем статическое поле static int _counter отличается от обычного поля?
Сколько копий этого поля существует в программе?
- в Dart _ делает идентификатор приватным для файла, а не для
класса. Одна копия
